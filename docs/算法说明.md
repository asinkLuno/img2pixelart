# 像素画生成算法

流水线分为三个阶段：**感知（perceive）** → **结构（structure）** → **渲染（render）**。

## 总览

```
输入图片 (BGRA)
    │
    ▼
┌──────────────────────────────┐
│ 1. 感知 (perceive)            │
│   去噪 → 色块化 → 色相族聚类    │
│   → 明度阶梯色板 → Canny 边缘  │
└──────────────────────────────┘
    │ (色相族标签、明度档位、色板、边缘)
    ▼
┌──────────────────────────────┐
│ 2. 结构 (structure)           │
│   降采样到 N×N 网格            │
│   → 轮廓 / 边界 / 细节线推导    │
└──────────────────────────────┘
    │ (网格化的 alpha、族标签、档位、轮廓、细节线)
    ▼
┌──────────────────────────────┐
│ 3. 渲染 (render)              │
│   抖动 → 轮廓暗化 → 输出 PNG   │
└──────────────────────────────┘
    │
    ▼
输出图片 (BGRA PNG)
```

## 一、感知阶段（perceive）

### 算法流程

**Step 1: 去噪 → 色块化**

输入图片先经 **双边滤波 (bilateral filter)** 去噪，再经 **Mean Shift 滤波** 将相似颜色区域合并为均匀色块。这一步的目的是减少后续颜色聚类时的噪声干扰，同时产生干净的颜色区域。

**Step 2: 色相族聚类**

将前景像素的颜色投影到 CIELAB 色彩空间的 $a^*b^*$ 平面，只有色度（chroma）足够高的像素才参与聚类。将这些像素投影到单位圆（即只保留色相方向，忽略色度大小），然后使用 **Spherical K-Means** 在单位圆上聚类，每个簇代表一个"色相族"（例如红色族、蓝色族）。

聚类完成后，角度过近的簇会被合并。低色度的前景像素归入一个独立的"中性族"（无色相方向），仅用明度来区分。

数学细节见 [色相环.md](%E8%89%B2%E7%9B%B8%E7%8E%AF.md)。

**Step 3: 明度阶梯色板**

对每个色相族（含中性族），统计其前景像素的明度分布，取低分位（`ramp_low_quantile`）到高分位（`ramp_high_quantile`）作为明度范围，均匀切分为 N 档阶梯。每档的颜色 = 该族的色相方向 × 该档的色度强度 × 该族的代表色度。

色度强度沿阶梯呈 V 形：两端衰减到 `ramp_endpoint_chroma_scale`，中间保持满色度。这模拟了"暗部灰度化、亮部泛白化"的自然光照感。

**Step 4: 明度分档**

将每个前景像素的明度就近分配到其色相族的明度阶梯中，得到 0..N-1 的档位（tier）。

**Step 5: Canny 边缘检测**

在去噪后的灰度图上运行 Canny 边缘检测，并与前景腐蚀掩码取交集，得到只位于前景内部的细节线。

### 配置项

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `denoise_d` | 9 | 双边滤波核直径（必须为正奇数） |
| `denoise_sigma` | 75 | 双边滤波颜色 Sigma，值越大保留的细节越多 |
| `mean_shift_sp` | 15 | Mean Shift 空间带宽，值越大色块越大 |
| `mean_shift_sr` | 40 | Mean Shift 颜色带宽，值越大色块越少 |
| `requested_groups` | 2 | 期望的色相族数量（不含中性族），实际可能因合并而减少 |
| `chroma_floor` | 5.0 | 色度下限。$a^*b^*$ 距离小于此值的像素归入中性族 |
| `merge_angle_degrees` | 10.0 | 簇合并角度阈值。两个簇中心夹角小于此值则合并 |
| `minimum_lightness` | 8.0 | 最低明度。L 低于此值的像素不参与聚类（太暗的颜色不可靠） |
| `minimum_fit_pixels` | 16 | 聚类最少需要多少个有效像素，不足则不建彩色族 |
| `maximum_fit_pixels` | 30000 | 聚类最多使用多少个像素（随机采样），控制计算量 |
| `random_seed` | 11 | K-Means 随机种子，固定可保证结果可复现 |
| `spherical_kmeans_iterations` | 20 | Spherical K-Means 最大迭代次数 |
| `ramp_steps` | 5 | 每个色相族的明度阶梯数（总色板大小 ≈ groups × steps） |
| `ramp_minimum_span` | 42.0 | 明度阶梯的最小跨度（L 值范围）。阶梯范围不足时会以中位数为中心向外扩展 |
| `ramp_low_quantile` | 0.04 | 明度下分位。阶梯最暗档对应的明度百分位 |
| `ramp_high_quantile` | 0.96 | 明度上分位。阶梯最亮档对应的明度百分位 |
| `ramp_minimum_family_pixels` | 8 | 色相族的最小像素数。不足的族借用全图统计量 |
| `ramp_chroma_quantile` | 0.5 | 每个族的代表色度取自该族色度分布的此分位 |
| `ramp_endpoint_chroma_scale` | 0.78 | 阶梯两端的色度衰减系数（相对于中间档）。0=端点灰度化，1=全阶梯等色度 |
| `ramp_maximum_chroma` | 80.0 | 色度上限，防止极端鲜艳的颜色 |
| `canny_low` | 65 | Canny 低阈值 |
| `canny_high` | 155 | Canny 高阈值 |
| `alpha_threshold` | 128 | Alpha 通道二值化阈值。alpha >= 此值视为前景 |

## 二、结构阶段（structure）

### 算法流程

**Step 1: 降采样到目标网格**

将感知阶段的所有全分辨率信息降采样到 `N×N` 的像素画网格（N 由 CLI `--size` 控制）：

- **Alpha 掩码**：INTER_AREA 面积平均后，覆盖率 >= `alpha_coverage` 的网格判为前景。
- **色相族 / 明度档位标签**：对每个网格取原区域内出现次数最多的标签（majority voting）。
- **明度图**：INTER_AREA 面积平均。
- **Canny 边缘**：INTER_AREA 面积平均后，覆盖率 >= `edge_coverage` 的网格判为边缘。

**Step 2: 结构线推导**

在降采样网格上推导四类结构线：

- **轮廓（silhouette）**：alpha 掩码内侧边界（腐蚀后消失的一圈），即精灵的外轮廓。
- **色相族边界（family boundary）**：相邻网格属于不同色相族的边界。
- **色阶边界（shade boundary）**：相邻网格属于不同明度档位的边界。
- **内部细节线（internal detail）**：Canny 边缘中靠近轮廓或色相族边界的部分，经细化（Zhang-Suen thinning）得到 1 像素宽的线。

**Step 3: 小尺寸精灵清理（`size <= 64` 时触发）**

当网格很小时，面积平均会留下大量杂点和破碎区域。此步骤：

- 闭孔（填充小洞）、去掉过小的孤立连通块。
- 局部多数投票平滑：在前景区域内，用 3×3 邻域的多数标签平滑色相族和明度档位。边界像素受保护不修改。
- 网格极小时（`<= 40`）直接关闭 Canny 细节线（此时 Canny 基本无意义）。

### 配置项

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `alpha_coverage` | 0.16 | 前背景判定阈值。网格内原图 alpha 覆盖率 >= 此值判为前景 |
| `edge_coverage` | 0.065 | Canny 边缘覆盖率阈值。网格内边缘覆盖率 >= 此值才保留 |
| `edge_min_length` | 2 | 内部细节线的最短连通分量长度（像素），更短的被删除 |
| `edge_canny_support_radius` | 1 | Canny 线搜索半径。只有在轮廓或族边界此半径范围内的 Canny 线才会被采纳为内部细节 |
| `edge_open_before_thin` | true | 细化前是否对内部细节做开运算（去毛刺） |
| `small_cleanup_threshold` | 64 | 小精灵清理触发阈值。网格尺寸 \<= 此值时进入小尺寸清理 |
| `small_detail_min_length` | 4 | 小尺寸下的内部细节线最短长度 |
| `small_cleanup_passes` | 2 | 局部多数平滑迭代次数 |
| `small_hole_close` | true | 是否对小尺寸 alpha 掩码做闭孔操作 |
| `small_tier_smooth_majority` | 5 | 明度档位平滑时的多数胜出最小票数。值越大越保守（改动越少） |
| `small_skip_canny_under` | 40 | 网格尺寸 \<= 此值时完全跳过 Canny 细节线 |

## 三、渲染阶段（render）

### 算法流程

**Step 1: 硬分档着色**

先将每个前景网格按 `(色相族, 明度档位)` 从色板中取对应颜色，得到一张无锯齿、无过渡的纯色块图（hard ramp）。

**Step 2: 连续位置插值**

将每个网格的明度线性映射到其色相族阶梯内的连续位置（0 到 steps-1 之间的浮点数），整数部分是当前档，小数部分是到上一/下一档的距离。

**Step 3: 抖动**

只在满足条件的区域应用抖动（有序 Bayer 或 Floyd-Steinberg 误差扩散），在两个相邻明度档之间按小数部分插值选档，产生伪半色调过渡。抖动区域需同时满足：

- 非轮廓、非色阶边界。
- 连续位置的小数部分在 `[dither_fraction_min, dither_fraction_max]` 内（即不在两端——太接近某档时不需抖动）。
- 局部明度梯度 >= `dither_gradient_min`（平缓区域不需抖动）。

**Step 4: 轮廓/细节暗化**

- **轮廓（silhouette）**：强制设为该色相族的最暗档（索引 = `silhouette_dark_step`）。
- **内部细节线**：强制设为比该网格当前档位暗 `internal_outline_dark_steps` 档（限定在族内）。

### 配置项

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `dither_method` | bayer | 抖动方法：`none`（无抖动）、`bayer`（4×4 有序抖动）、`floyd_steinberg`（误差扩散） |
| `dither_fraction_min` | 0.18 | 抖动的连续位置小数部分下限。小数部分 < 此值不参与抖动（已很接近某档） |
| `dither_fraction_max` | 0.82 | 抖动的连续位置小数部分上限。小数部分 > 此值不参与抖动 |
| `dither_gradient_min` | 0.8 | 抖动所需的局部明度梯度下限。梯度 < 此值的平缓区域不抖动 |
| `silhouette_dark_step` | 0 | 轮廓像素使用的明度档位（0 = 该族最暗档） |
| `internal_outline_dark_steps` | 1 | 内部细节线比当前档位暗几档 |
