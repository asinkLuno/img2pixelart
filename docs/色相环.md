# CIELAB 色彩空间与色相环

本文档记录 img2pixelart 项目中涉及的色彩知识，以 CIELAB（CIE 1976 L\*a\*b\*）色彩空间为核心。

______________________________________________________________________

## 为什么用 CIELAB

像素画生成需要在**感知均匀**的色彩空间里工作，才能让算法对颜色的判断与人眼一致。RGB / HSV 都不是感知均匀的——两个颜色在 RGB 里的欧氏距离未必反映人眼看到的差异。

CIELAB 设计目标之一就是**感知均匀**：空间中两点距离 ≈ 人眼感知的颜色差异。因此我们的聚类、色相判断、明度阶梯全部在 Lab 空间完成。

______________________________________________________________________

## L\*a\*b\* 三个通道

OpenCV 的 `COLOR_BGR2LAB` 转换结果为 float32：

| 通道 | 含义 | 取值范围 |
|------|------|----------|
| **L\*** | 明度（lightness） | 0（黑）～ 100（白） |
| **a\*** | 绿 → 红轴 | 负值偏绿，正值偏红，0 为中性 |
| **b\*** | 蓝 → 黄轴 | 负值偏蓝，正值偏黄，0 为中性 |

______________________________________________________________________

## a\*b\* 平面：色相环

a\* 和 b\* 构成一个二维平面，**原点 (0, 0) 代表中性灰**（无色度）。

### 色度（Chroma）

像素在 a\*b\* 平面上到原点的**欧氏距离**：

$$
C = \\sqrt{a^2 + b^2}
$$

- C = 0 → 纯灰（无彩色信息）
- C 越大 → 颜色越鲜艳/饱和

项目中的 `chroma_floor` 就是色度阈值：低于它的像素归入**中性族**（无色相），
因为色度太低时色相角不可靠——噪声就能让一个近乎灰色的像素算出任意角度。

### 色相角（Hue Angle）

像素在 a\*b\* 平面上的**方向**（以 a\* 轴正方向为 0°）：

$$
\\theta = \\operatorname{atan2}(b, a)
$$

$$
\\theta \\in (-\\pi, \\pi\]
$$

大致对应关系：

| 角度 | 颜色 |
|------|------|
| 0° | 红（+a\*） |
| 90° | 黄（+b\*） |
| 180° / -180° | 绿（-a\*） |
| -90° | 蓝（-b\*） |

### 单位色相向量（Hue Direction Vector）

将 a\*b\* 坐标归一化到单位圆上，只保留色相方向，丢弃色度大小：

$$
\\vec{d} = \\frac{(a, b)}{|(a, b)|\_2}
$$

这样做的目的：**聚类色相族时不关心颜色多鲜艳，只关心偏红还是偏蓝。**

## Spherical K-Means：在单位圆上聚类

### 为什么不是普通 K-Means

普通 K-Means 在 a\*b\* 平面上直接聚类会出问题：

- 一个深红和一个亮红距离很远，但它们共享同一个色相方向
- 一个低色度的淡红可能比高色度的正红更靠近正蓝（因为原点附近所有角度混在一起）

所以在单位圆上聚类：**先归一化为方向向量，再用余弦相似度（内积）衡量远近**。

### 算法概要

1. 随机选 K 个像素的方向向量作为初始中心
1. **分配**：每个像素按其方向向量与各中心的内积（越大越近）分配归属
1. **更新**：每族取所有成员方向的均值向量，再归一化回到单位圆上
1. 重复直到标签不再变化或达到迭代上限

### 空簇处理

若某簇没有成员：选一个与当前所有中心**最不相似**（最小内积）的像素方向作为新中心。

## 色相族（Hue Families）

### 彩色族

Spherical K-Means 聚类后，每个簇代表一个**色相族**——共享相同色相方向的颜色集合。
例如：红色族、蓝色族、黄色族。

### 中性族

不满足聚类条件的像素归入**中性族**：

- 色度 < `chroma_floor`（太灰，色相不可靠）
- 明度过低（太暗，颜色不可靠）

中性族的色相方向向量 = [0, 0]，即**只靠明度区分**，色度始终为 0。

### 簇合并

聚类后角度过近的簇会按固定阈值合并。
合并阈值用余弦衡量：两个中心方向的内积达到该阈值即视为相邻，
找出所有连通分量后分别取均值。

______________________________________________________________________

## 明度阶梯（Lightness Ramp）

每个色相族内部，按明度 L\* 从暗到亮切分为 N 档阶梯。

### 明度范围

取该族像素明度的固定 4% 到 96% 分位，并保证跨度至少为 `ramp_minimum_span`。范围不足时以中位数为中心向两侧扩展。

### 色度 V 形衰减

每档的颜色 = 族的色相方向 × 档位色度。色度沿阶梯呈 **V 形**分布：

```
色度
 │
 │    ████              ← 中间档保持满色度
 │   ██████
 │  ████████
 │ ██████████
 │████████████           ← 两端衰减到固定比例
 └──────────────→ 明度
   暗            亮
```

物理直觉：

- **暗部灰度化**：阴影下颜色饱和度自然降低
- **亮部泛白化**：高光区域颜色被光源"洗白"
- **中间保持鲜艳**：正常照明的物体颜色

衰减公式（`positions` 线性映射到 [-1, 1]，中间在最暗/最亮中间）：

```
chroma_scale[i] = 1.0 - (1.0 - 0.78) × |position[i]|
```

中间档 `position ≈ 0` → `chroma_scale ≈ 1.0`（满色度），
两端档 `position ≈ ±1` → `chroma_scale ≈ 0.78`（衰减）。

### 代表色度

每族的 base chroma 固定取自该族像素色度的中位数。
每档的实际色度 = base_chroma × chroma_scale，再受固定色度上限约束。

## 固定调色板匹配（fit 模块）

指定固定调色板时，原图仍负责决定色相族和明暗结构。随后每条自适应 ramp
在进入渲染前匹配到调色板：

1. 自适应 ramp 与固定调色板都转换到 Lab
1. 每个 ramp 档位取 Lab 距离最近的调色板颜色
1. 抖动只在匹配后的同族相邻档之间进行
1. 轮廓压暗后只在所属 ramp 内取最近色

调色板只约束可用颜色，不改变原图的分色结果，避免宽色板把相邻的红、粉、橙
错误拼成一条阶梯。最终输出中的非透明像素严格属于指定调色板。

______________________________________________________________________

## 抖动：如何在 Lab 空间做

渲染阶段的抖动发生在**单个色相族内部**——只在同一族的相邻明度档之间选择。

这样做的原因：

- 跨族抖动会产生脏色（如红色族像素混入蓝色族像素）
- 同族内不同明度档只有明度差异，抖动过渡自然

### 三种抖动

| 方法 | 原理 |
|------|------|
| **Bayer 有序** | 4×4 阈值矩阵，按像素坐标平铺，小数部分与阈值比较决定上下档 |
| **Floyd-Steinberg** | 误差扩散，量化误差传播到右/下/左下/右下邻域，仅同族像素 |
| **微图案（pattern）** | 17 个 4×4 二值图案字典，小数部分量化到 0/16～16/16 覆盖率再查表 |

三种共享同一逻辑：连续位置的小数部分决定两档之间的"插值权重"，抖动将其转化为空间上二值分布的伪半色调。

## 色相环概览图

```
                      +b* (黄)
                        │
                        │  90°
                        │
         橙            │            黄绿
                        │
                        │
     ──────────────────(0,0)────────────── +a* (红)
         蓝绿          │   0°          橙红
                        │
                        │
         蓝            │            紫
                        │
                        │  -90°
                        │
                      -b* (蓝紫)
```

- 原点 = 中性灰，色度 0
- 任意点到原点的距离 = 色度 C
- 任意点到原点的方向 = 色相角 θ
- 单位圆上的点 = 纯色相方向（色度 1）
